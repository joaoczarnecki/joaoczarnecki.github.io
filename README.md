# joaoczarnecki.github.io

Personal research site of **João Paulo Czarnecki de Liz** (Université Laval): forest ecology, species distribution
models, lidar and the TCAMS app. Live at <https://joaoczarnecki.github.io>.

Plain HTML, CSS and JavaScript; no build step. Open `index.html` in a browser to preview.

- `index.html`: the page (English text).
- `assets/i18n.js`: Portuguese and French translations (keys match the `data-i18n` attributes).
- `assets/main.js`: links (`LINKS` at the top: add Google Scholar, ResearchGate, LinkedIn there), language and theme
  switches, counters, lightbox, the community-suitability demo and the lidar-scan animation.
- `assets/img/`: figures from the author's studies; put a square photo at `assets/img/photo.jpg` to replace the initials.

Author: João Paulo Czarnecki de Liz, with Claude (Anthropic) as coding assistant. Code MIT; text and figures CC BY 4.0.
